1. List Types — what we sell

Tax Delinquent List
Property owners who owe back taxes to the county. At least one year behind, sometimes more. Motivated sellers because they're facing tax sale or foreclosure. We get this from county tax commissioner records — public info.
Pre-Foreclosure List
Properties where the bank or court started foreclosure but the sale hasn't happened yet. Owner is under pressure, often motivated. Window before the bank takes it. Source: county court filings.
Absentee Owner List
Owner's mailing address ≠ property address. They don't live there — they're a landlord or investor. Out-of-state absentee = mailing is in a different state, even more motivated.
Probate List
Properties tied to a deceased person's estate. Heirs need to settle and often want fast sale. Motivated sellers. Source: county probate court.
Lien List
Properties with a legal claim — unpaid contractor bills, court judgments, HOA violations. Owner can't sell clean without paying them off. Some will negotiate.
Vacant Land
Undeveloped lots. For builders, developers, buy-and-hold investors.
Permit Burnout Lane
Properties with open or recent damage permits — fire loss, demolition, storm, emergency. Owner overwhelmed with repairs. This is our term, not industry standard.
Entity vs Individual Owner
Entity-owned: LLC, corp, trust, REIT. Harder to reach, registered agent required.

Individual-owned: Real person's name. Can be called directly.

2. Data Terms — what's inside the list

Parcel ID / APN
Unique county ID for that piece of land. Like a social security number for a property.
Situs Address
The actual physical address of the property. Where the building sits. "Situs" = Latin for "location."
Mailing Address
Where the county sends tax bills. Where the OWNER gets their mail. Could be a different state.
Market Value / Assessed Value
Market value = county's estimate of what it's worth.
Assessed value = the value used to calculate taxes (usually a % of market).
Distress Score (0–100)
Our number for how motivated the owner likely is. Higher = better lead. Built from tax balance owed, out-of-state status, damage permits, delinquency length.
Lane
A specific category within a market. Charlotte has multiple lanes — tax delinquent, absentee, lien. Same county, different filter. Our internal word.
Snapshot / Discovery Snapshot
Processed, ready-to-sell batch. We took raw data (200K rows), filtered, scored, cleaned, kept the top 500-2,000. That's the snapshot. Our internal word.

3. Industry Terms — REI World

Wholesaling
Buying a contract to purchase a property at a discount, then selling that contract to another investor before closing — without ever owning the property. Wholesalers are our biggest customer type.
MAO — Maximum Allowable Offer
The most a wholesaler/investor will pay and still make money.
Formula: (ARV × 70%) − Repair Cost = MAO
ARV — After Repair Value
What the property would sell for after it's fixed up. Used to back-calculate what to pay today.
Skip Tracing
Finding a property owner's phone and email when not publicly listed. Services: BatchSkipTracing, REIPro, IDI. Our lists are address-only — customers skip-trace if they want phones.
DNC — Do Not Call Registry
Federal list. Calling someone on it without consent = fines. Our lists are address-only so DNC is the customer's responsibility, not ours.
TCPA
Telephone Consumer Protection Act. Federal law on cold calls and texts. Customer compliance, not ours.
Direct Mail
Physical postcards or letters to the owner's mailing address. Works with our lists because we provide mailing addresses.

4. Tech Terms — Our Stack

VPS — Virtual Private Server
A computer in a data center running 24/7. Ours is at Hostinger. Where Danny lives and all raw data is stored.
Supabase
Our database in the cloud. The dashboard reads/writes here. Stores leads, prospects, messages, agent activity.
GitHub / GitHub Pages
GitHub stores our code. GitHub Pages is free hosting that turns code into live websites — that's how all your URLs work.
CSV vs XLSX
CSV: plain comma-separated text. Opens anywhere.
XLSX: Excel format. Multi-tab, colors, fonts. Our branded delivery files.
RLS — Row Level Security
Database permissions that control who can read/write each row. We have this set up so random people can't read your customer list.
Cron Job
A scheduled task that runs automatically at set times. Danny's Wake NC cron pulls fresh data every day at 6am.
Webhook
When system A automatically notifies system B that something happened. Twilio → dashboard when a text comes in, for example.
MCP — Model Context Protocol
How Claude/Codex connect to external tools like Supabase. When you see "Supabase MCP connected" it means I can run database commands directly.
n8n
Visual workflow builder. Connect boxes: "when X happens, do Y." Free, runs on the VPS, automates between all our tools.
