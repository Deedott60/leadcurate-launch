# Brand DNA Commercial System — Notes

## Visual / carousel idea
- Create a different kind of carousel where each swipe feels like part of the product/environment is being assembled or revealed.
- Reference feeling: luxury watch scroll/build effect, but adapted to other business categories.
- Goal: make carousels feel more cinematic, interactive, and less like standard static slide decks.
- This should be explored as a reusable visual language for client work and for our own marketing.

## Important direction
- Treat this as a **business/system idea**, not personal context.
- Use Codex/ChatGPT image workflows and premium visual references to prototype it.
- Could later be used on Facebook/X content if platform access/accounts are set up.
