# Proactive Business Execution

Use when Derrick wants movement, not brainstorming.

## Goal
Convert an idea into the smallest executable business path without drifting into generic agency fluff.

## Sequence
1. Name the business/system
2. State the offer in one sentence
3. Check visible demand or adjacent proof
4. Define the smallest proof asset
5. Define the first paid offer
6. Define the first distribution lane
7. Define the stop condition if traction is weak

## Deliverable format
- business name
- one-sentence offer
- proof asset to build first
- who it is for first
- where to place it first
- what counts as first traction
- what to do next if it works
- what to stop if it doesn't

## Rules
- Do not widen into full platform fantasies too early
- Do not replace execution with endless ideation
- Prefer first buyer logic over big vision unless the user asks for strategy
