# Business Index Sync

Use when Derrick is brainstorming or managing multiple businesses, systems, or product ideas at once.

## Goal
Keep a recoverable list of:
- business names
- system/product names
- which are active vs future
- where their working docs live

## Rules
- Add names to the repo index when they become real enough to revisit later.
- Separate shared/system assets from business-specific assets.
- Do not bury every future business under one business's folder without noting the distinction.
- When a name is unknown, store a working name until corrected.

## Minimum fields
- Name
- Type (business / system / supporting tool)
- Status (active / future / paused)
- Home folder or index location

## Recovery use
Later, the user should be able to ask:
- what businesses are we tracking?
- what systems have we named?
- where do those notes live?
