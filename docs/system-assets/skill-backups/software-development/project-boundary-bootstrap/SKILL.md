# Project Boundary Bootstrap

Use whenever Derrick starts discussing a new business, offer, or product direction.

## Required minimum
- Project name (working name is fine)
- One-sentence goal
- Whether this is:
  - an existing business
  - a new business idea
  - a supporting system/tool
- Where its notes should live

## Rules
- Do not let one business bleed into another just because they live in the same repo temporarily.
- If the exact name is unknown, propose one and use it consistently until corrected.
- Add the business/system name to the future-business or system-assets index when appropriate.
- Keep shared/system docs separate from project-specific docs.

## Quick starter format
- `Project:`
- `Type:`
- `Goal:`
- `Primary folder/index:`

## Trigger examples
- new city alert idea
- new media product
- new portal/productized service
- new automation system
