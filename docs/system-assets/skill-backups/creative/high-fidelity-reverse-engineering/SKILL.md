# High Fidelity Reverse Engineering

Use when Derrick wants to duplicate or adapt something that looks premium.

## Break the target down into layers
1. Hook / first impression
2. Visual system (colors, type, layout, density)
3. Motion system (pace, transitions, reveals, scroll behavior)
4. Story structure
5. Asset types used
6. Tool stack likely used
7. What is hard to copy vs easy to copy

## Rules
- Do not stop at "it looks cool".
- Identify the repeatable production method.
- Separate premium finish from expensive-but-unnecessary parts.
- If something looks high-level, specify exactly what creates that feeling.

## Output
Return:
- what it is
- why it looks high-end
- what to mimic first
- what tools/process are needed
- cheapest acceptable version
- what would make the output turn into slop
