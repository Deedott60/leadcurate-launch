# Ad Format Pattern Scanner

Use when Derrick wants to know if a trend/product/video format is worth reverse-engineering.

## Questions to answer
1. What is the format in one sentence?
2. Why is it working now?
3. Is the visual trick the value, or the underlying offer?
4. Can businesses easily imagine their own version?
5. Is it becoming saturated already?
6. Can it be productized into a repeatable workflow?
7. Fastest path to first $200 / $2k?

## Reverse-engineering posture
- Identify reusable structure, not just surface style
- Separate trend hook from evergreen business use
- Look for mascot/location/product/environment hooks
- Ask whether the format creates inbound demand ("Can you do this for me?")

## Output format
Return:
- format summary
- copyability score
- saturation risk
- best first niche
- minimum tool stack
- should we pursue it: yes/no
