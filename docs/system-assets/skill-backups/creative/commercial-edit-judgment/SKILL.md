# Commercial Edit Judgment

Use when Derrick asks whether a commercial feels premium or like slop.

## Evaluate these dimensions
1. Hook quality in first 2 seconds
2. Human realism / trust
3. Shot order and scene logic
4. Camera calmness vs hyperactive cutting
5. Hold time per shot
6. Subtitle readability and restraint
7. Product-demo contamination (too much UI/process)
8. End-card clarity and brand fit
9. Emotional promise: what feeling does the viewer leave with?

## Default standards
- Premium trust ad: 4–7 second shot holds
- Fewer shots beats more shots
- One emotional promise per ad
- Human scene before product scene
- White/light end card is preferred for trust-heavy brands unless brand rules say otherwise

## Anti-slop rules
- If it looks like a template reel, reset
- If product UI dominates, cut it back
- If transitions attract more attention than the message, simplify
- If subtitles are doing all the work, the visuals are weak

## Output format
Return:
- what works
- what feels cheap
- what to cut
- what to regenerate
- one clear next version plan
