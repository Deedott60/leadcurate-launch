# Brand DNA Commercial System

Use when Derrick wants to turn a business into repeatable promo content without generic slop.

## Goal
Extract the business's actual identity and convert it into reusable creative assets:
- brand DNA
- hooks
- commercial script angles
- UGC-style prompts
- mascot/environment rules
- intake fields for an automated portal

## Brand DNA extraction
Always identify:
1. What the business actually sells
2. Who it is for
3. What emotion it should trigger
4. What visual world it belongs in
5. What would make the content instantly recognizable as *their* business
6. What should never appear because it would break trust or feel off-brand

## Output blocks
For each business, generate these blocks:

### 1. Brand DNA
- tone
- visual identity
- environment cues
- character/owner/mascot cues
- emotional promise
- anti-patterns

### 2. Hook bank
Create short hooks for:
- promo reels
- commercial-style opens
- UGC opens
- event/special hooks
- product/offer hooks

Hooks should be short, concrete, and usable on-screen or in voiceover.

### 3. Script bank
Generate scripts in these buckets:
- premium commercial
- UGC-style testimonial/demo
- quick promo / social spot
- offer/special push
- mascot-led or environment-led promo if relevant

### 4. Scene system
Map scripts into repeatable scene types:
- real environment hero shot
- owner/team shot
- hands/product shot
- process shot
- customer experience shot
- clean brand lockup/end card

### 5. Portal intake requirements
For automation/productization, define what the customer must upload:
- logo
- brand colors/fonts if available
- flyer or offer text
- 3 to 10 real location photos
- mascot/character assets if any
- menu/product photos if relevant
- preferred vibe references
- CTA and booking/contact link

## Anti-slop rules
Do not let the system default to:
- generic AI agency copy
- random nightclub flyer style unless that is the actual brand
- fake luxury office scenes for ordinary businesses
- overdesigned motion with no emotional point
- mascot use that feels disconnected from the business's real environment

## Automation/product thinking
When Derrick wants this turned into a product, think in this order:
1. intake form
2. file upload
3. payment
4. brand-DNA extraction step
5. hook/script generation step
6. scene prompt generation step
7. human QA checkpoint
8. delivery package

The product should sell a repeatable *system*, not just one-off creative labor.
