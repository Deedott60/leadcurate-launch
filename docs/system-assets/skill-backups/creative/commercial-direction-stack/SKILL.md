# Commercial Direction Stack

Use when Derrick asks what roles/skills are needed so a commercial stays on track emotionally, visually, and strategically.

## Core roles to simulate
1. Creative Director
   - defines the idea, tone, audience promise, and what the ad should feel like
2. Copywriter / Script Lead
   - writes the voiceover and on-screen lines
3. Storyboard Director
   - turns the script into 5-7 concrete scenes with purpose
4. Director / Cinematic Lead
   - chooses shot size, camera motion, lighting, blocking, pace
5. Editor
   - controls timing, transitions, and what gets cut
6. Sound Director
   - voice casting, pacing, music bed, sound mix
7. Brand QA
   - asks: does this feel premium, human, and on-message, or does it feel like slop?

## Minimum checkpoints
Before generating:
- clear audience
- one emotional promise
- one visual style reference
- one approved script direction

Before final delivery:
- human realism check
- subtitle readability check
- pacing check
- end-card clarity check
- brand-fit check

## Anti-slop rule
If the ad feels like a tech demo, motion-template reel, or generic AI video, stop and reset before spending more.
