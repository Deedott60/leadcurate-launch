# Non-Generic Creative Ideation

Use when Derrick asks for ideas, opportunities, products, or monetization angles.

## Hard rejects
Do not suggest:
- chatbots
- generic AI agencies
- audits as the main idea
- cold outreach as the core engine
- obvious 2023 AI side-hustle ideas
- mass-produced local-business automation fluff

## Required bar
Only suggest ideas that satisfy at least 3 of these:
1. Newly unlocked by recent model/tool changes
2. Low-supply operator edge
3. Existing user behavior already proves demand
4. Fast path to first dollars
5. Can become a repeatable system
6. Likely to get crowded later, so being early matters

## User preference
The user wants:
- early, underexploited opportunities
- motion / visual / media products over generic AI service offers
- direct, blunt evaluation
- no repeated recycled suggestions after rejecting a lane
- once a lane is rejected, treat it as blacklisted for the rest of the session unless the user explicitly reopens it
- if the user says a lane is dead (for example chatbots, audits, generic automation agencies), treat that lane as blacklisted for the rest of the ideation session instead of sneaking it back in with new wording
- stay inside the requested lane; if the user asks about Charlotte/local-signal/media ideas, do not pivot back to generic service offers
- if the user rejects an idea family once, do not keep re-proposing adjacent variants just because they are easy to explain
- when discussing motion/media offers, do not default to generic motion-flyer hustle advice; distinguish clearly between low-value template flyer work and higher-value custom real-environment / mascot / business-specific visuals
- if the user asks for fast money, do not pitch traffic or content businesses as fast-money paths unless the monetization path is concrete and direct

## Motion/media ideation rule
Treat "generic motion flyers" as a weak default unless there is a real edge.

Prefer motion/media angles that use:
- the customer's real storefront, interior, team, mascot, or product photos
- believable custom AI-enhanced scenes tied to the actual business
- repeated packaging systems (hero visual + short promo + caption + offer variant)
- niche fit where the environment itself matters (restaurants, food spots, food trucks, lounges, family brands, attractions)

Avoid pitching motion/media ideas as strong if they mainly rely on:
- generic template motion
- Canva/CapCut-looking flyer churn
- nightclub-style visuals for every niche
- obvious AI slop with no real-business grounding

## Output format
For each idea:
- What it is in 1 sentence
- Why now
- Why it is not generic
- Fastest path to first $200 / $2k
- Main risk

If no idea clears the bar, say so plainly instead of forcing weak ideas.
