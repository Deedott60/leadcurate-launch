# Project Preflight Checklist

Use this before any new project execution.

## Required questions
1. What is the exact goal?
2. What deliverable are we trying to produce?
3. What tools are required?
4. Which tools are already available?
5. Which tools are missing?
6. What fallback tools can be used if the main tool is unavailable or failing?
7. What is the exact step order?
8. What is the smallest proof step before spending more?
9. What is the stop condition if the tools are not good enough?

## Output format
- Project name
- Goal
- Deliverable
- Required tools
- Available tools
- Missing tools
- Fallback tools
- First proof step
- Execution order
- Stop condition

## Rule
Do not start execution until this is answered.
