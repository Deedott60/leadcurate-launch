# Capability Check Order

Use this order whenever Derrick asks whether something can be done.

1. Is the capability already available?
2. If not, can it be installed here?
3. If not, can it be connected through an account/session?
4. If not, can another agent/tool do it?
5. Then answer yes/no clearly.

## Required answer format
- Current capability: yes/no
- Installable here: yes/no
- Needs account/access: yes/no
- Best next step: one sentence
