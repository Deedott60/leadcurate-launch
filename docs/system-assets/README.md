# Skills and Agent Recovery Index

This folder tracks reusable Hermes assets that should be recoverable from GitHub.

## What belongs here
- skill names
- agent names
- purpose summaries
- folder conventions
- future system components to rebuild if needed

## Naming conventions
### Skills
Format:
- `skill:<category>/<name>`

Examples:
- `skill:creative/non-generic-creative-ideation`
- `skill:creative/commercial-direction-stack`
- `skill:software-development/user-stop-signal-discipline`

### Agents
Format:
- `agent:<domain>/<name>`

Examples:
- `agent:autonomous-ai-agents/reverse-engineering-agent`
- `agent:marketing/brand-analyst` (future)
- `agent:sales/outreach-qualifier` (future)

## Important note
These are not always running background agents. In Hermes, many "agents" are saved as reusable skills/agent playbooks that can be loaded later.
