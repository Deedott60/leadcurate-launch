The process — raw record → sellable lead

Every list a buyer pays for travels this 6-stage pipeline. Most competitors stop at stage 2. This is where the value lives.

1
Source identification

For each county, identify the exact public-record endpoint — tax collector portal, ArcGIS feed, PDF roll, court calendar, assessor parcel database. Document the access method, headers, pagination quirks, and refresh cadence. Every county is different. This is the moat.

2
Automated pull

Scripted retrieval running on a dedicated VPS — direct CSV/JSON pull, Playwright headless browser for blocked portals, PDF parsing with pdfplumber. Cron-scheduled. Records refreshed within 24 hours of the county updating their roll. Buyer is working signal that's days old, not months.

3
Normalization + enrichment

Raw county fields mapped to a unified schema — parcel ID, situs address, mailing address, owner name, owner type (individual vs entity), market value, assessed value, tax balance, delinquency period, permit history. Cross-referenced against assessor data to fill gaps. Junk records dropped.

4
Distress scoring

Proprietary 0–100 score computed per record. Weighted signals: tax balance owed, delinquency length, out-of-state mailing flag, entity ownership, open damage permits, property value tier, year built, sale history. Higher score = more motivated owner = higher conversion for the buyer.

5
Filtering + segmentation

Source data is cut into stacked-filter products — Tax Delinquent, Absentee + Tax Delinquent, High-Equity Absentee, Probate, Pre-Foreclosure, Code Violation. Same raw pool, multiple sellable segments per market. Multiplies revenue per pull.

6
Branded delivery

Final batch packaged as a multi-tab XLSX with cover sheet, source attribution, refresh date, and a redacted preview. Buyer receives a polished asset — not a CSV dump. Perceived quality lifts price tolerance. Repeat-buy rate climbs because the experience matches the price.

What's different

Three things that separate this from PropStream and the recycled-list market.

Direct from county source

We don't buy from data brokers. Every record is pulled from the actual county tax collector, court records, or assessor — same morning, same week, never resold across thousands of competitors.

Scored, not dumped

Every record runs through a distress-signal scoring algorithm. Out-of-state mailing, entity ownership, year built, value range, permit history — each weighted, summed, ranked. Buyers get the top of the funnel, not the whole flat file.

Limited buyer access

We deliberately cap the number of buyers per county. The same list isn't being hammered by 100 wholesalers — it's being worked by 1–3. Records stay warm. Conversion stays high.
