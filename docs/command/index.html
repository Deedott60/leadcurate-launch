How LeadCurate OS works
Your operator manual. Bookmark this page or hit ⌘K → "Help" anytime.
The big picture

This is your business OS — think Salesforce, but built for you, free, and designed to expand as you add automations. Three things happen in here:

  1. Find prospects → add them manually to the Pipeline, OR send them the intake link and let them fill the form (lands in Inbox)
  2. Work them through the pipeline → use templates to reach out, send previews, quotes, payment instructions, delivery emails
  3. Watch the system run → as you wire up Codex, Hermes, Twilio, Stripe, they each push events here so you can monitor without micromanaging
Each page, what it's for

⚡ HQ — your morning glance. Stats up top, recent inbound, activity feed. If you only open one page, open this.

📥 Inbox — every intake form submission lands here in real time. Click "→ Pipeline" on any row to push them into outreach.

📊 Pipeline — your kanban board. Two ways prospects get here:
  • Manually: use the "Add prospect" form at the top (people YOU found on FB, IG, etc.)
  • From Inbox: click "→ Pipeline" on an intake submission
Move them through 7 stages: Queued → Reached out → Replied → Preview sent → Quote out → Paid → Delivered.

💬 Messages — manually log every SMS / DM / email you send or receive. In Phase 2 this fills automatically via Twilio webhooks.

🔁 Workflow — agent + integration status. Green dot = connected, grey = waiting. This is where Codex, Hermes, Twilio, n8n, Stripe will plug in.

📋 Templates — 15+ copy-paste messages organized by symbol: ★ pipeline (preview, payment received, delivery), ☞ replies (how much, sample only, DNC question), $ payment (Cash App, Zelle, Stripe), ⤴ post-delivery (check-in, recurring upsell, referral ask). Tap to copy.

📣 Marketing — Phase 2 placeholders for email campaigns, mass SMS, Meta + Google Ads, social outreach log, affiliate tracking.

🔎 SEO / GEO — Phase 2 placeholders for traditional search rank tracking + GEO (how often ChatGPT/Claude/Perplexity recommend you).

The status dot in the top bar

● synced = Supabase database is connected and live. Your data is syncing across devices.

○ offline = Supabase unreachable. Dashboard still works locally via your browser storage; data will sync when connection returns.

Pipeline stages explained

Queued — you added them, haven't reached out yet

Reached out — you sent them the intake link or initial message

Replied — they responded (filled intake OR replied to message)

Preview sent — you sent them a redacted sample of their requested list

Quote out — you gave them a price + payment instructions

Paid — money received

Delivered — full file shipped to them

Dead — went cold, mark and move on (can revive later)

Keyboard shortcuts + tips

⌘K or Ctrl+K — open command palette (go to any page, log an event, add prospect, export)

🔗 Copy intake link button in top bar — grab the URL to paste in any DM/SMS/email instantly

Click any prospect card → opens detail drawer with stage selector + delete + copy-message button

Tap any template in Templates → auto-copies to clipboard

Activity feed entries are searchable — add events from the HQ or Workflow pages so the timeline reflects what you've been doing

When something new gets added

All of this is editable. New markets, new list types, new templates, new pipeline stages — they live in the HTML and can be updated any time. As you learn what real customers actually ask for, the OS tightens around that.

If you want a new page, new automation, new integration — just say what it should do. The pattern is established now; adding to it is fast.
